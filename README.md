📜 Smart Contract Summary & Q&A Assistant
An AI-powered tool designed to simplify legal document analysis. This assistant allows users to upload smart contracts (PDF/DOCX), generates instant summaries of key terms, and provides a conversational interface to ask specific questions about the document's clauses.

🚀 Features
Automated Summarization: Extracts parties, termination clauses, and payment terms instantly.

Conversational RAG: Chat with your documents using Retrieval-Augmented Generation.

High Performance: Powered by Groq (Llama 3.1/4) for near-instant inference.

Cost-Efficient: Uses HuggingFace local embeddings to avoid OpenAI usage fees.

Modern UI: Clean, tabbed interface built with Gradio.

🛠️ Tech Stack
Framework: FastAPI, LangChain (Core & Classic)

LLM: Groq (Llama-3.1-8b-instant)

Vector DB: ChromaDB

Embeddings: HuggingFace (all-MiniLM-L6-v2)

Frontend: Gradio
